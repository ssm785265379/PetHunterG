# 口播稿 v2：短句流（6 分 09 秒）

> 按你给的参考稿风格重写：**一句 2–3 秒、口语、能直接念**。
> 文件三件套：
> - `restore-apk-voiceover-v2.json` —— 字幕时间轴（`from/to/sid/location/content/music`，和你给的那份同结构，可直接进剪映/CapCut）
> - `restore-apk-voiceover-v2-table.md` —— 169 行对照表（时间 + 口播）
> - 本文件 —— 用法、分段、画面与删减方案
>
> 技术底稿仍是 [restore-old-apk-video-script.md](restore-old-apk-video-script.md)（18–22 分钟版）；这版是**照着念的成片版**。

## 一、怎么用

1. **直接当字幕**：JSON 字段和参考稿一致，导入剪辑软件的"字幕/文稿匹配"即可（`content` 是文本，`from/to` 是秒）。
2. **照着念**：打开 `restore-apk-voiceover-v2-table.md`，一行一句，别连读。
3. **念法**：短、平、快。像跟朋友解释，不要播音腔；每句结尾略停 0.2 秒。
4. 每句已按字数给了时长（1.6–4.5 秒），念快了就留白，念慢了就剪。

## 六、念之前提醒自己三句

1. **别解释原理，先说现象**：「点了没反应」「一启动就崩」比「协议解析失败」好听。
2. **每段留一个钩子**：「这个 Tab 记住，后面救你一命」。
3. **敢认错**：「我烧过两天」「帮助文本也会骗人」——观众信这个，不信全知全能。
