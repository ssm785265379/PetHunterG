## 四、客户端限制（服务端改不了，必须改 APK 资源）

- 养成页固定 9 格、**没有翻页控件** —— "没有页码"是客户端结构问题。
- 字号溢出、图鉴文字不居中、倍速按钮、音乐叠加 —— 都是 SWF 资源/渲染层。
- 家园里混着显示宠物道具 —— 同一个 22 号响应，服务端无法按界面过滤。

这些要动就得改 SWF 并重新打包；我可以做，但每改一次都要你重装 APK。

## 五、运维与安全

1. **公网无鉴权**（最重要）：`http://43.173.99.241:8080/` 任何人可访问，日志里已经能看到
   互联网扫描器在打 `/hachk.php`。建议至少加 nginx IP 白名单或 basic auth。
2. **存档没有自动备份**：目前只有部署脚本"保留远端存档"这一层保护。
   建议加每日定时备份（保留 7 天）。
3. **SSH 用 root 密码**：建议改密钥登录并更换密码。
4. **存档回迁**：本地那份已经过期，需要时从 `/opt/pethunter/instance/game.sqlite3` 拉回。
