### 1.2 命令与归档

```powershell
cd F:\git\PetHunterG

# 1) 默认抓「PetHunterG desktop preview」
powershell -ExecutionPolicy Bypass -File .\tools\preview-shot.ps1 -Name login

# 2) 多窗口：按 lane 标题抓
powershell -ExecutionPolicy Bypass -File .\tools\preview-shot.ps1 -Title "PetHunterG preview [b1]" -Name bag-popup

# 3) 只抓客户区（去掉标题栏）
powershell -ExecutionPolicy Bypass -File .\tools\preview-shot.ps1 -ClientArea -Name main-home
```

| 项 | 规则 |
|---|---|
| 归档 | `docs\preview\<yyyy-MM-dd>\<HHmmss>-<Name>.png`；`Name` 里的非 `\w-` 字符替换成 `-` |
| 抓取前 | 窗口必须还原并置前；被遮挡/最小化会抓成黑/花 |
| 自检 | 看 stdout 的「非黑占比」，接近 0% 是窗口没画出来 |
| 缩放 | `-Width 640 -Height 960` 可把 150% 缩放抓到的 960×1440 缩回去 |

### 1.3 坐标口径（重要：本轮**不是**「截图 ÷2」）

| 截图来源 | 像素尺寸 | 坐标怎么读 |
|---|---|---|
| **本文三张：ADL 窗口抓图** | **640×960，与窗口 1:1** | **直接读截图像素 = 桌面逻辑像素，不 ÷2** |
| 真机 `adb screencap` | 1080×2412 | ÷2 → 540×1206 逻辑像素 |

所以本文所有坐标都写「ADL px（640×960，1:1）」。拿到 1080×2412 真机图时，把表里的数 ÷2 再和真机图比。

另外：桌面 640×960 与真机 540×1206 的宽高比不同（约 0.667 vs 0.448），文档没写两者换算规则；
本文不推，真机布局只能用真机截图核对。

## 2. 评审清单（38 条）

怎么用：每条打 ✓ / ✗ / N/A；✗ 必须标级别。
分级：**P0** = 看不清 / 点不到 / 挡操作，必须修；**P1** = 明显影响体验或跨页不一致，本轮修；
**P2** = 打磨，记看板。
尺寸：逻辑像素。桌面 640×960 下 1px 就是 1 窗口像素；1080×2412 真机图里同一条要 ×2（如 44 → 88）。
